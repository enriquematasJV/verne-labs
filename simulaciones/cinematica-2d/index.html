Modelo matemático
El movimiento se descompone en eje horizontal y vertical.
x(t) = x₀ + v₀x·t
y(t) = y₀ + v₀y·t - 1/2·g·t²
v₀x = v₀·cos(θ), v₀y = v₀·sin(θ)
Aunque el movimiento se describe con ecuaciones en función del tiempo, en muchos problemas se introduce una segunda relación equivalente sin tiempo: v² = v₀² - 2·g·(y - y₀). Esta ecuación se obtiene eliminando el tiempo entre v(t) y y(t), y permite calcular alturas directamente. Por ejemplo, en la altura máxima se cumple v = 0, y entonces: 0 = v₀² - 2·g·(y - y₀) → se obtiene la altura sin usar t.
