1. Presentación

En esta unidad vas a utilizar una simulación interactiva para estudiar el movimiento de una pelota en dos dimensiones. Trabajarás con un laboratorio virtual donde podrás modificar la altura inicial, la velocidad, el ángulo de lanzamiento y la gravedad.

El objetivo no es simplemente observar una trayectoria, sino investigar: hacer predicciones, ejecutar la simulación, interpretar las pausas automáticas, relacionar los resultados con las ecuaciones y explicar físicamente lo que ocurre.

Vertical Tiro hacia arriba

La pelota sube, se frena, alcanza una altura máxima y cae. Permite estudiar la condición vᵧ = 0.

Horizontal Caída desde altura

La pelota avanza en horizontal mientras cae verticalmente. Permite observar la independencia entre X e Y.

Parabólico Trayectoria completa

La velocidad inicial se descompone en v₀x y v₀y. La trayectoria resultante es una parábola.

2. Objetivos de aprendizaje

  • Comprender el movimiento vertical bajo aceleración constante.
  • Interpretar el tiro parabólico como combinación de dos movimientos independientes.
  • Relacionar las ecuaciones de posición y velocidad con lo que se observa en la simulación.
  • Usar correctamente el convenio de signos: derecha positiva, arriba positivo y gravedad negativa.
  • Calcular altura máxima, tiempo de vuelo, alcance y velocidad de impacto.
  • Formular hipótesis, comprobarlas con la simulación y extraer conclusiones razonadas.

4. Ecuaciones que vas a utilizar

El movimiento se estudia separando el eje horizontal y el eje vertical. En este laboratorio se toma como referencia el suelo para el eje Y.

x(t) = v₀x · t
y(t) = y₀ + v₀y · t - 1/2 · g · t²
vᵧ(t) = v₀y - g · t

Para resolver problemas no basta con escribir una fórmula: debes reconocer la condición física adecuada.

  • Altura máxima: vᵧ = 0.
  • Llegada al suelo: y = 0.
  • Movimiento horizontal: la velocidad vₓ permanece constante.

5. Situaciones de aprendizaje

Cada situación de aprendizaje funciona como una pequeña investigación dentro del laboratorio. El simulador proporciona el entorno, pero el aprendizaje aparece cuando observas, comparas, calculas y justificas tus conclusiones.

Situación de aprendizaje 1: ¿Qué ocurre en la altura máxima?

Tiro vertical MRUA vᵧ = 0

Pregunta inicial: ¿por qué la pelota se detiene un instante en el punto más alto si la gravedad sigue actuando?

Antes de comenzar, escribe una hipótesis sobre lo que crees que ocurrirá con la velocidad y la aceleración.

  1. Selecciona el escenario de tiro vertical.
  2. Configura una velocidad inicial de 25 m/s.
  3. Activa las pausas automáticas.
  4. Ejecuta la simulación hasta la altura máxima.
  5. Anota los valores de tiempo, altura y velocidad vertical.
Preguntas guía:
  1. ¿Cuánto vale vᵧ en la altura máxima?
  2. ¿La aceleración vale cero en ese punto?
  3. ¿Qué ecuación permite calcular el tiempo de subida?
  4. ¿Qué ocurre con el signo de vᵧ después del punto más alto?
  5. ¿Cómo se calcula la altura máxima una vez conocido el tiempo?

Situación de aprendizaje 2: Caída horizontal desde una altura

Lanzamiento horizontal Independencia X/Y

Pregunta inicial: si una pelota sale horizontalmente, ¿por qué acaba cayendo?

Intenta anticipar si el tiempo de caída depende de la velocidad horizontal.

  1. Selecciona lanzamiento horizontal desde altura.
  2. Fija una altura inicial de 40 m.
  3. Realiza una prueba con v₀ = 10 m/s y otra con v₀ = 40 m/s.
  4. Compara el tiempo de caída y el alcance horizontal.
Preguntas guía:
  1. ¿El tiempo de caída cambia al modificar la velocidad horizontal?
  2. ¿Qué magnitud sí cambia claramente?
  3. ¿Qué ecuación determina el tiempo de caída?
  4. ¿Qué ecuación determina el alcance?
  5. ¿Qué significa que los movimientos X e Y sean independientes?

Situación de aprendizaje 3: Descomposición de la velocidad inicial

Tiro parabólico v₀x v₀y

Pregunta inicial: ¿cómo cambia la trayectoria cuando se modifica el ángulo de lanzamiento?

Observa si aumentar el ángulo siempre aumenta el alcance.

  1. Selecciona tiro parabólico completo.
  2. Fija v₀ = 30 m/s y y₀ = 0 m.
  3. Prueba con ángulos de 15°, 30°, 45°, 60° y 75°.
  4. Registra el alcance y la altura máxima en cada caso.
Preguntas guía:
  1. ¿Qué ocurre con v₀x al aumentar el ángulo?
  2. ¿Qué ocurre con v₀y?
  3. ¿Qué ángulo produce mayor alcance en tus pruebas?
  4. ¿El ángulo de mayor altura coincide con el de mayor alcance?
  5. ¿Por qué la trayectoria tiene forma parabólica?

Situación de aprendizaje 4: Cambiar la gravedad

Investigación Comparación aᵧ negativa

Pregunta inicial: ¿cómo cambiaría el lanzamiento si la gravedad fuese menor o mayor?

Usa el laboratorio como entorno de investigación y compara trayectorias manteniendo los mismos datos iniciales.

  1. Selecciona tiro parabólico.
  2. Fija v₀ = 25 m/s y θ = 45°.
  3. Prueba con diferentes valores de gravedad.
  4. Observa tiempo de vuelo, altura máxima y alcance.
Preguntas guía:
  1. ¿Qué ocurre si la gravedad disminuye?
  2. ¿Qué ocurre si la gravedad aumenta?
  3. ¿Cambia la velocidad horizontal?
  4. ¿Qué magnitudes se ven más afectadas?
  5. ¿Por qué la aceleración vertical tiene signo negativo?
