Sobre el proyecto

Verne Labs es una colección de laboratorios interactivos pensados para aprender mediante la experimentación. Las simulaciones están desarrolladas con tecnologías web estándar, por lo que pueden ejecutarse directamente desde el navegador sin instalar programas adicionales.

La página principal funciona como índice general. Desde aquí se podrá acceder a cada simulación y, cuando exista, a su unidad didáctica correspondiente. Todos los enlaces son rutas relativas, así que este mismo index.html funciona tanto si lo abres directamente desde tu ordenador como si el proyecto está publicado en GitHub Pages.
